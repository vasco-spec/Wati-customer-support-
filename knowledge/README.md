# Support knowledge base

This folder is what Claude reads before answering GalgoSheets customers. It has no memory between sessions, so **anything that isn't written here, it won't know.**

| File | What's in it |
|---|---|
| [product-overview.md](product-overview.md) | What GalgoSheets is, who uses it, its modules and integrations, the weekly workflow |
| [faq.md](faq.md) | Recurring customer questions, with the answer the team usually gives (in Portuguese) |
| [known-issues.md](known-issues.md) | Things that are often "wrong" but are expected, plus current incidents. **Update this when something breaks.** |
| [video-library.md](video-library.md) | Loom videos the team already sends to customers, grouped by topic |
| [escalation.md](escalation.md) | Who handles what, and what Claude must never do or promise |
| [open-questions.md](open-questions.md) | Things Claude couldn't work out from the conversations. Please answer these. |

## Status

**First draft, 12 Nov 2026.** It's based on 766 WhatsApp conversations from 14 Aug to 12 Nov 2026, 353 of them with replies from the team. Everything here was *inferred* from how the team answered customers, so it may contain mistakes. Items marked ⚠️ need confirming.

## How to update

- Edit the Markdown files directly, or tell Claude in the support session ("add to the FAQ that…").
- Keep customer data out of this folder: no names, phone numbers, emails, NIFs or passwords.
- Next source to add: Loom transcripts (see open-questions.md).
